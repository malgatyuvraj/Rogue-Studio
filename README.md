## ⚡ Feature Deep Dive

### 🤖 Autonomous Agent Mode
The AI writes files, executes shell commands, reads output, debugs errors, and loops autonomously until the task is complete. Full filesystem access. No token limits. No output truncation. No permission prompts. Give it a goal, walk away, come back to working code.

### ⚔️ Red Team vs Blue Team Swarm
Two adversarial AI agents battle in real-time:
- **Blue Team** writes the code
- **Red Team** immediately attacks it (XSS, SQLi, reentrancy, overflows)
- Vulnerabilities found → auto-fed back → Blue Team patches
- Re-audited until verified secure (max 3 iterations)
- Both streams visible in real-time split terminal

### 🎯 Attack Chain Engine
Autonomous multi-phase pentesting — one target, full pipeline:
```
Recon → Vuln Scan → Exploit → Verify → Report
```
Each phase uses specialized prompts. Findings aggregate across phases. Auto-pivots on failure.

### 🔒 Air-Gap Mode (Kill Switch)
One toggle. **Completely offline.** Server-side enforced `403 Forbidden` on all external providers. Only local Ollama allowed. Middleware-level enforcement — impossible to bypass from client. Zero bytes leave your machine.

### 💣 Payload Forge
- Multi-stage encoding: XOR → AES → Base64 chains
- Polymorphic shellcode generation
- Platform targets: Linux/Windows/macOS × x86/x64/ARM
- AV evasion wrappers and obfuscation layers
- Reverse shells, bind shells, staged payloads

### 🎯 Zero-Day Fuzzer
- 6 mutation strategies: random, bitflip, arithmetic, havoc, dictionary, grammar-aware
- AI-guided seed selection with coverage tracking
- Crash triage with exploitability scoring (high/medium/low)
- Auto-corpus generation from format specifications

### 🪖 War Room — 5-Agent Operations
Coordinated attack simulation with shared intelligence board:

| Agent | Role |
|-------|------|
| **Recon** | Surface mapping, port scanning, tech fingerprinting |
| **Exploit** | Vulnerability exploitation, payload delivery |
| **Exfil** | Data extraction, covert channels |
| **Cleanup** | Trace removal, log wiping, persistence removal |
| **Defense** | Countermeasure development, detection rules |

Phases: Planning → Active → Exfiltrating → Cleanup → Complete

### 👻 Ghost Deploy
Deploy untraceable services with one click:
- **Tor**: Generate `.onion` hidden service with streaming bootstrap
- **IPFS**: Content-addressed pinning via local Kubo or Pinata
- **Arweave**: Permanent, censorship-resistant storage
- Zero DNS. Zero registrars. Zero paper trail.

### 📡 Chain Monitor
- Real-time Ethereum/BSC/Arbitrum mempool surveillance
- Sandwich attack detection and MEV analysis
- Flash loan opportunity enumeration
- Strategy classification: frontrun, backrun, arbitrage, liquidation
- Whale movement alerts with configurable thresholds

### ⚙️ Binary Necromancy
- Auto-detect ELF/PE/Mach-O formats from magic bytes
- Dangerous import analysis (system, exec, VirtualAlloc, mmap)
- ROP gadget discovery for exploitation
- Hardcoded secret extraction (API keys, passwords, tokens)
- Radare2 + objdump integration for deep disassembly

### 💀 Contract Exploit Engine
- Pattern matching: reentrancy, access control, flash loan, oracle manipulation
- Auto-generates complete exploit contracts
- Outputs Foundry test harnesses ready to run
- Supports Solidity 0.6.x through 0.8.x

### 🎭 Identity Rotation
- Ethereum wallet generation (fresh keypairs)
- Disposable email addresses
- Browser fingerprint randomization
- Proxy rotation with configurable intervals
- Cross-platform consistent personas for red team ops

### 🕵️ Dark Web OSINT
- Ahmia search engine integration
- Have I Been Pwned breach lookups
- IntelX intelligence queries
- .onion endpoint crawling via Tor
- Target dossier compilation

## 🔌 Plugin System

Extend Rogue Studio with custom modes in seconds:

```typescript
import { RoguePlugin } from "@/lib/plugins";

export default {
  id: "my-custom-mode",
  name: "Custom Mode",
  category: "security",  // security | development | analysis | web3 | intelligence | operations | anonymity | infrastructure
  systemPrompt: "You are a specialized AI that...",
  icon: "⚡",
} satisfies RoguePlugin;
```

14 built-in plugins. Drop new ones in `src/plugins/` — auto-registered.
